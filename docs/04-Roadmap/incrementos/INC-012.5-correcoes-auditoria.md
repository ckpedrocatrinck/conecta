# INC-012.5 — Correções pré-piloto (Balde 1 das auditorias)

**Status:** ⬜ Não iniciado
**Fase:** transversal (correção), entre INC-012 e o polimento (DP-13/14) / INC-013
**Depende de:** auditoria-2026-07.md + auditoria-usabilidade-2026-07.md (ambas concluídas)
**Origem:** triagem das duas auditorias — só o "Balde 1" (bug real, vergonha na frente do usuário, ou risco de segurança). Polimento visual → DP-13/DP-14. Hardening/anonimização → INC-013. Dívida controlada → backlog.

## Princípio de escopo
NÃO é "corrigir tudo". É corrigir o subconjunto que **bloqueia o piloto**: bugs funcionais, coisas que envergonham na frente do usuário (anti-padrão do portal legado), e reforços de segurança baratos. Tudo que for polimento visual/estético fica para o DP-13/DP-14 (redesenho com Claude Design) para não gerar retrabalho. Tudo que for hardening/LGPD de operação continuada fica para o INC-013.

## Escopo — organizado em 3 blocos revisáveis

### BLOCO A — Segurança e backend (correções de infra/núcleo)
- **A2-1 (ALTO):** middleware bloqueia `/api/cron/publish-announcements` → comunicado agendado nunca auto-publica. Excluir `api/cron` do matcher (ou curto-circuitar antes da auth), deixando o Bearer-secret do handler governar.
- **A4-1 (ALTO):** adicionar triggers de imutabilidade (BEFORE UPDATE/DELETE + BEFORE TRUNCATE, padrão `forbid_*_mutation` do ack) a `announcement_versions` e `audit_logs`. Migration manual (ADR-008), `migrate deploy`.
- **A4-3 (MÉDIO):** checagem de boot de que a conexão runtime é `conecta_app` não-superuser (`current_user` + `rolsuper=false`), falhando o start caso contrário. Documentar no `.env.example`.
- **A4-4 (MÉDIO):** ano da sequência CI derivado em America/Sao_Paulo, não UTC (evita `CI 01/AAAA+1` na janela 21h-23h59 BRT de 31/dez).
- **A2-3 (MÉDIO):** liberar `/manifest.webmanifest`, `/icon-*.png`, `/offline` no matcher/PUBLIC_PATHS (PWA instalável na tela de login).

### BLOCO B — Robustez de UX (erro, loading, feedback)
- **Q1 (QUEBRADO):** criar `error.tsx`, `not-found.tsx` e `loading.tsx` de rota em pt-BR, usando os componentes órfãos `ErrorState`/`Loading`/`EmptyState`. Acabar com "Application error" em inglês (anti-padrão do portal legado §0.5).
- **R8-R13 (RUIM):** eliminar falhas silenciosas do colaborador — aplaudir, carregar mais, candidatar/cancelar, consentimentos: dar feedback de erro e confirmação de sucesso; recarregar/avisar em vaga fechada.
- **R14/R15/R16 (RUIM):** admin — confirmação de sucesso + estado `pending` nas ações de broadcast (publicar comunicado/post, fechar vaga, cobrar pendentes, salvar filial); **confirmação destrutiva** para ações irreversíveis (arquivar comunicado, desligar colaborador, remover filial, remover foto).

### BLOCO C — Correções de usabilidade que envergonham
- **Q2 (QUEBRADO):** aviso de privacidade — não exibir o placeholder "PENDENTE-JURÍDICO" ao usuário final (bloquear a rota enquanto for placeholder OU usar um texto interino digno); dar saída ("Sair") a quem não aceita, em vez do beco sem saída. (Texto jurídico definitivo é pendência do INC-013/jurídico — aqui é só não envergonhar e não prender.)
- **R1 (RUIM):** alvos de toque ≥48px nas ações-chave do colaborador (candidatar-se, aplaudir, chips de filtro, Sair, trocar foto, ativar push). Corrigir no `Button` de ação mobile / componentes.
- **R17/R23 (RUIM):** datas ISO/UTC cruas no admin (agendamento, histórico, `datetime-local` de vaga) → `formatDateTimeSaoPaulo`/hora local.
- **R18 (RUIM):** traduzir `user.role` exibido na lista de colaboradores (inglês visível → pt-BR).
- **R2 (RUIM/decisão):** bottom nav — decidir e implementar comportamento fixo (com `dvh`/safe-area) OU assumir não-fixa; hoje o comentário do código mente. (O polimento fino de desktop/Safari fica no DP-13; aqui só resolver a inconsistência funcional.)

### BLOCO D — Testes
- **A7-1 (MÉDIO):** estabilizar os testes flaky — trocar `DISABLE/ENABLE TRIGGER` global por `SET LOCAL session_replication_role = 'replica'` dentro da transação de limpeza (session-scoped, sem mutar catálogo). Verde do CI confiável antes do go-live.

## Fora de escopo (explícito)
- Polimento visual: header, card PNG/Figtree, cores hardcoded→tokens, nav deformada em desktop, logout no chrome, identidade do usuário → **DP-13/DP-14**.
- Anonimização de desligados, retenção, rotação de pepper, texto jurídico definitivo, gate de onboarding nas APIs, `ON DELETE` do audit → **INC-013**.
- N+1 do push (DP-17), postcss, `updateMany` padronizado, e todos os MELHORIA → **backlog**.

- [ ] App falha o start se a role runtime não for `conecta_app` não-superuser.
- [ ] Ano do CI usa America/Sao_Paulo (teste de fuso na virada de ano).
- [ ] PWA instalável/manifest/ícones acessíveis deslogado.
- [ ] Erro e 404 mostram tela em pt-BR (nunca "Application error"); loading de rota existe.
- [ ] Nenhuma ação do colaborador ou admin falha silenciosamente; ações destrutivas pedem confirmação.
- [ ] Aviso de privacidade não expõe "PENDENTE-JURÍDICO" e oferece saída.
- [ ] Alvos de ação-chave ≥48px.
- [ ] Datas do admin em horário de São Paulo; `role` em pt-BR.
- [ ] Testes flaky estabilizados (suíte verde de forma determinística).
