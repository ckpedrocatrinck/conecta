## Princípio-mestre
**Muda a PELE, não o funcionamento.** Toda a lógica (server actions, guards de autorização, withTenant, hash de ciência, RLS, triggers, corrida hash-vs-edição) fica INTOCADA. Este INC mexe em: tokens (globals.css / Tailwind), componentes-base de UI, JSX de apresentação, e o gerador de card PNG. NUNCA na camada de dados nem nos fluxos. Se uma mudança visual exigir tocar lógica → PARAR e perguntar.

## Decisões travadas (variações A/B escolhidas por Pedro)
- **Header admin → B** (duas camadas: faixa de identidade fina em verde-profundo #275F4C com nome/empresa/filial/Sair + trilho de navegação com indicador de seção ativa).
- **Home do colaborador → A** (lista priorizada: pendência → aniversariante de hoje → feed → vagas; "o que preciso fazer" acima do social, leve na primeira dobra).
- **Card PNG → A** (campo verde-profundo denso, Figtree real, wordmark; vitrine do WhatsApp).

## Princípios inegociáveis (do design-system §0, reafirmados)
1. Laranja #D96E30 (`--action`) EXCLUSIVO de ação do usuário. Nunca decoração.
2. Verde #2F7A5F + neutros = base.
3. Figtree única.
4. Mobile-first 360px, alvos ≥48px.
5. Anti-portal legado.
6. Três estados de comunicado inequívocos (cor + rótulo).
